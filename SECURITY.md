# Security

These skills are Markdown instructions plus one standard-library Python script (`skills/production/scripts/readiness.py`). They do not fetch or run remote code.

If you find a security problem, such as instructions that could lead an agent to take harmful actions or a flaw in the script, report it privately through [GitHub private vulnerability reporting](https://github.com/miisodev/skills/security/advisories/new). Please do not open a public report.

Always review a skill before installing it. The same applies to any skill, from any source.
