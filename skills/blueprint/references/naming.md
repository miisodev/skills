# Naming — the owner-run availability check

The blueprint records the owner's naming decision; this reference is the checklist so the agent never half-does the availability work. Naming is the owner's taste; availability is evidence. Public aggregators are preliminary evidence only — official registries decide.

## The check, in order

1. **Search the official registries, not aggregators, and wait for results.** A blocked, unloaded or errored search is unverified — do not conclude availability from it.
   - **US:** USPTO's trademark search (tmsearch.uspto.gov); read the goods/services class(es) the name would cover and the related, coordinated classes — a name in an adjacent class can still conflict.
   - **International:** WIPO's Global Brand Database for multi-register coverage; national and regional registers where the markets are known.
2. **Record what was searched, per class, with the query and the date**, in the workbook. Availability is a dated statement, not a vibe.
3. **Domain and handle availability** are separate facts from trademark availability — check both, record both.
4. **Do not conclude from silence.** "Nothing came up" means nothing came up in that register on that date. An owner decision to proceed despite an unresolved search is the owner's, recorded as a decision.

## Where it lands

- The decision (name, classes searched, date, verdict, any owner risk acceptance) goes in the workbook.
- The name, positioning and voice go in `brand.md` — the check itself never enters the document; only the decision does.
