# <Project>: Blueprint

The foundation this project is built on: why it exists, who it serves, how it wins, whether it makes money, what it is made of and where it is going. It was established with the project's owner and records their intent, the market's reality and the money's limits.

**If you are building, designing, marketing or running this project, read the documents in order before making decisions.** They set intent and constraints. They deliberately leave design, architecture, data models, interfaces and copy to you. Where your work changes something here (a requirement proves wrong, a cost breaks the economics), raise it with the owner so the blueprint can be revised. Don't route around it.
